# 프로젝트 진행 기록

프로젝트를 진행하며 내린 결정, 문서 수정, 검토·확인 내역을 날짜순으로 정리한 기록입니다. 1·2차 요구사항의 프로젝트 관리 항목(산출물·논의사항 추적, 이슈와 해결 상황 기록)의 근거로 씁니다.

- 날짜와 시간은 한국 시간(KST)입니다. 커밋과 PR은 GitHub 기록과 같습니다.
- 결정 사항은 팀원 동의를 받은 뒤 코드와 문서에 반영했습니다.
- 운영 규칙은 [프로젝트 관리 규칙](project-management.md), 카드별 진행 상황은 [백로그 진행 현황](requirements2-backlog.md)에 있습니다.
