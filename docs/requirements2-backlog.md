## 갱신 방법

1. 카드를 가져갈 때: 이슈 담당자를 지정하고 보드에서 "진행 중"으로 옮긴다. 이 표의 상태를 🔄로 바꾸고 담당과 시작일을 적는다. 진행 중인 카드는 한 사람당 1장이다.
2. PR이 머지되면: PR 본문의 `Closes #번호`로 이슈가 닫혔는지 확인한다. 이 표의 상태를 ✅로 바꾸고 완료일과 PR 번호를 적는다. 요약 표의 카드 수도 고친다.
3. 팀 아이템(9~11번)은 아이템이 정해지면 카드 이름을 실제 아이템 이름으로 바꾼다.
