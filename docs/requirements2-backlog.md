- 담당: A(1차 `core`·`ui`), B(1차 `application`·`storage`·`bootstrap`)
- 날짜 형식: `YYYY-MM-DD`
- 상태: ⬜ 대기 / 🔄 진행 중 / ✅ 완료

## 갱신 방법

1. 카드를 가져갈 때: 상태를 🔄로 바꾸고 담당과 시작일을 적는다. 진행 중인 카드는 한 사람당 1장이다.
2. PR이 머지되면: 상태를 ✅로 바꾸고 완료일을 적는다. 아래 요약 표의 카드 수도 고친다.
3. 팀 아이템(9~11번)은 아이템이 정해지면 카드 이름을 실제 아이템 이름으로 바꾼다.
