# 평가 준비와 데모 순서

평가는 팀별로 진행되며, 평가 항목(Requirement specification)은 강의 시간 평가 이후에 제시됩니다. 따라서 모든 요구사항을 빠짐없이 보여 줄 수 있도록 미리 준비합니다. 요구사항별 충족 여부는 [요구사항 추적표](requirements-traceability.md)로 확인합니다.

## 1. 준비물

| 준비물 | 용도 | 확인 |
| --- | --- | --- |
| 데모용 노트북 (Windows 11) | 게임 시연, 코드·테스트·GitHub 보여 주기 | 충전기, 화면 밝기 |
| 평가용 노트북 또는 태블릿 | 다른 팀 평가 항목 완료 여부 체크 | 브라우저, 평가 양식 접속 |
| 최신 배포 zip | 시연에 쓸 실행 파일 | GitHub Releases 최신 버전을 미리 받아 압축 해제 |
| [아이템 명세서](item-specification.md) | 평가팀에 제공 (2차 요구사항) | 화면 또는 인쇄본으로 바로 보여 줄 수 있게 |

## 2. 평가 전날 확인

- [ ] `main`에 모든 카드가 머지되었고 [요구사항 추적표](requirements-traceability.md)에 ❌·⚠️ 항목이 없음
- [ ] GitHub Releases에 최신 버전 zip이 있음
- [ ] 데모 노트북에서 zip을 새로 풀어 `SETetris.exe`를 더블클릭해 실행됨 (Java가 없는 상태에서도 실행되는지)
- [ ] `.\gradlew.bat clean build jacocoTestReport`가 통과하고, 커버리지 보고서를 열 수 있음
- [ ] GitHub의 Issues, Pull Requests, Actions 화면과 Trello 보드에 바로 접속 가능
- [ ] 시연용 기록 정리: 필요하면 설정에서 스코어보드를 초기화하거나, 미리 몇 판을 플레이해 순위표에 기록을 남겨 둠

## 3. 데모 순서

평가팀이 체크리스트 순서로 확인하기 쉽도록 실행 → 메뉴 → 설정 → 일반 모드 → 종료 → 아이템 모드 → 관리 기록 순서로 보여 줍니다.

| 순서 | 보여 줄 것 | 관련 ID |
| --- | --- | --- |
| 1 | 배포 폴더의 아이콘 있는 `SETetris.exe` 더블클릭 실행 | N1-08 |
| 2 | 시작 메뉴: 게임 이름, 메뉴 항목, ↑↓·Enter, 다른 키를 누르면 사용 가능 키 표시 | R1-01~04, R2-10 |
| 3 | 설정: 화면 크기 3종, 키 변경(겹치는 키 거부), 색맹 모드, 난이도, 기본값 복원 | R1-19~21, R2-01 |
| 4 | 프로그램을 껐다 켜서 설정이 유지되는지 확인 | R1-22 |
| 5 | 일반 모드: 보드 20×10, NEXT, 현재 모드·난이도 표시, 점수 실시간 변화, 1초 낙하, 이동·회전·한 번에 떨어뜨리기, 키 반복 | R1-05~11, R1-16 |
| 6 | 블록 색·무늬 구분, 색맹 모드에서 다시 확인 | R1-14~15 |
| 7 | 일시정지·재개(P), 게임 메뉴(Esc)에서 메뉴로·프로그램 종료 | R1-12~13 |
| 8 | 줄 삭제와 애니메이션, 10줄 후 레벨·속도 증가 | R1-07, R1-09, R2-03, R2-06 |
| 9 | 게임 오버 → 이름 입력 → 순위표 강조 → 메뉴로 | R1-23~26 |
| 10 | 스코어보드: ←→ 난이도, ↑↓ 모드 구분 | R2-05, R2-11 |
| 11 | 아이템 모드: 10줄 후 NEXT에 아이템 블록, 아이템별 효과 ([아이템 명세서](item-specification.md) 5장 확인 방법) | R2-12~17 |
| 12 | 확률 분포 테스트(`WeightedRandomGeneratorTest`, `AppCompositionTest`)와 커버리지 보고서 | R2-07~09, N1-05 |
| 13 | GitHub Issues·PR·Actions, Trello 보드, [백로그 진행 현황](requirements2-backlog.md) | N1-02~04, N2-01~03 |

## 4. 시연 시간 주의

- 아이템은 누적 10줄마다 하나씩, 무작위로 나옵니다. 아이템 5종을 모두 보이려면 최소 50줄 이상을 지워야 하므로 실제 플레이만으로는 시간이 부족할 수 있습니다.
- 대비 방법
  - 아이템별 효과는 자동 테스트(`TeamItemsInEngineTest` 등)와 [아이템 명세서](item-specification.md)의 그림으로 먼저 설명하고, 실제 플레이에서는 나오는 아이템만 보여 줍니다.
  - 시연을 맡을 사람이 미리 연습해 10줄을 빠르게 지울 수 있게 합니다.
- 줄 삭제가 잘 안 될 때를 대비해 일반 모드 시연은 easy 난이도(I블록이 더 자주 나옴)로 합니다.
